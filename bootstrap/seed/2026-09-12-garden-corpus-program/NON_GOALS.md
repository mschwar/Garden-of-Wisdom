# Deferred scope

W0 is documentation and contract work only.

Do not use W0 to choose or migrate a production datastore, build new runtime interfaces, automate large-scale collection, perform bulk verification, replace the current browser, or redesign the existing canonical corpus.

Later waves should add complexity only when the preceding gate demonstrates the need. In particular, storage technology, semantic search, graph infrastructure, large-scale automation, and higher-order recommendation features remain deferred decisions.

Classification should remain faceted rather than forcing overlapping domains into one exclusive category. Curation, research, corpus status, and execution status must remain distinguishable concepts.
