# OWNER INTENT

Garden of Wisdom is a personal, curated collection of memorable passages from multiple religious/philosophical traditions for memorization and reflection. It should remain distinct from `bahai-homepage`.

The goal of this phase is to turn a fragile 2025 CSV repository into a legible, agent-first personal quote library and curation workbench, while preserving its history and uncertainty.

A second goal is to build a simple static quote browser/audit console so a human can easily look at, search, sort, filter, copy, inspect, and quality-check the database.

A later goal — NOT authorized yet — is to export a tiny verified Bahá’í subset as a test collection for `bahai-homepage`.

## G2 — data rehabilitation

Preserve before repair.

1. Preserve the original CSV bytes in an archival location or git-appropriate immutable record before normalization.
2. Diagnose the encoding/corruption mechanism from evidence. Do not guess-and-replace character sequences casually.
3. Produce valid UTF-8 canonical working data.
4. Do not rewrite quote wording to make it “look right” unless the transformation is a provable encoding restoration.
5. Preserve legacy IDs even if non-contiguous.
6. Add an explicit representation for at least:
   - quote/item type (`full-passage`, `excerpt`, `paraphrase`, `oral-attribution`, `unknown` or justified equivalents),
   - verification/review status,
   - source/provenance linkage.
7. Reconcile the source manifest into a structurally valid form.
8. Remove tracked `.DS_Store` and add an ignore rule.
9. Add deterministic validation that reports, at minimum:
   - parse validity,
   - duplicate IDs,
   - missing required fields,
   - malformed UTF-8,
   - invalid controlled values,
   - exact duplicate text,
   - suspicious/near-duplicate candidates where practical,
   - unresolved source links,
   - counts by quote type and verification status.

If a schema migration would destroy useful legacy information, preserve the legacy data and create a normalized layer rather than rewriting destructively.

## G3 — static quote browser/audit console

Build the simplest durable interface that materially improves human curation.

Required behavior:
- opens from a local static server and is suitable for GitHub Pages later;
- global text search across quote/author/source/tags;
- sort by at least ID, tradition, author, source and length;
- filters for tradition, author, source, tag, quote type and verification status;
- visible total and filtered counts;
- one-click copy quote;
- one-click copy quote + attribution;
- copy record JSON or equivalent machine-readable representation;
- expandable provenance/details;
- visible issue badges / an “issues only” view;
- duplicate/near-duplicate review aid if the validator emits candidates;
- responsive enough for laptop/mobile review;
- no backend, auth, analytics, runtime AI, database or framework unless you can demonstrate a framework is truly necessary.

The browser must make uncertainty visible. It must not visually present every row as verified scripture.
