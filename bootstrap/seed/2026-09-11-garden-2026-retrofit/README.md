# Garden of Wisdom packet

This is a **retrofit**, not a greenfield rewrite.

The first agent must preserve history and original data before normalizing anything.

The target is a small, durable personal quote library with:
- agent-readable repo doctrine,
- explicit data contract,
- deterministic validation,
- repaired UTF-8 working data with preserved raw/original bytes,
- a static HTML quote browser/audit console,
- a queue for later provenance verification,
- a clean export seam for downstream consumers.

Run Prompt 01 first. Prompt 02 is gated behind human review.
