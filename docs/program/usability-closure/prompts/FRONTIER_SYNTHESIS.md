# Frontier synthesis prompt

Use this only at a declared synthesis point.

You are doing frontier review, not implementation.

Reconstruct the actual system from current main, gate packet, persistent artifacts, CI, and live/local surface. Compare the gate's promised operator outcome with what a real person can now do.

Do not reward artifact count. Ask:
- what can I do now that I could not do before?
- can I resume tomorrow without tacit memory?
- can failure/staleness be silent?
- did the walking skeleton gain an end-to-end segment?
- what is the narrowest remaining seam?
- is the next planned unit still the shortest route?

Return:
- gate verdict with evidence;
- remaining gap list separated into BLOCKER / DEPENDABILITY / DEFERRED;
- recommended next authorization text only, never implicit authorization.
